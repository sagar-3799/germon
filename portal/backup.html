How to Publish on Cloudflare Pages & GitHub Pages
Option A: Deploy to GitHub Pages
  1. Open your project folder in terminal or Git Bash.
  2. Commit all files: git add . && git commit -m "Germon IT Portal Complete"
  3. Push to your GitHub repository: git push origin main
  4. In your GitHub Repo: Go to Settings → Pages.
  5. Under Branch, select main and click Save.
  6. Your site will go live at https://<username>.github.io/<repo>/!
Option B: Deploy to Cloudflare Pages (Recommended - Fastest in Nepal)
  1. Log in to your free Cloudflare Dashboard.
  2. Navigate to Workers & Pages → Create Application → Pages → Connect to Git.
  3. Select your GitHub repository Germon-IT-Website.
  4. Leave Build settings empty (Framework preset: None, Output directory: root).
  5. Click Save and Deploy.
  6. Your portal and website will be live worldwide on Cloudflare's ultra-fast edge CDN with free SSL!
